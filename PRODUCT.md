# Product

## Register

product

## Users

Table tennis hobbyists, amateur players, and community contributors who want to compare rubbers, blades, and boosters without reading scattered forum posts one by one. Many users arrive from mobile links shared in communities, while maintainers may use GitHub to submit or review equipment data.

## Product Purpose

Table Tennis Gear Database helps users filter equipment by practical tags, inspect images and notes, read community tendencies, and contribute corrections or new items. Success means ordinary players can quickly narrow options, and semi-technical contributors can improve the data without feeling the project is only for programmers.

## Brand Personality

Practical, trustworthy, community-minded.

## Anti-references

Do not make it feel like a marketing landing page, a decorative card gallery, or a toy app. Avoid exaggerated colors, oversized empty spacing, hard-to-read small labels, and hidden controls that make dense equipment comparison slow.

## Design Principles

- Let equipment data lead; interface decoration should stay quiet.
- Prefer compact, readable controls that support repeated filtering and comparison.
- Treat community data as subjective tendencies, not official truth.
- Make contribution paths approachable for non-programmers while keeping JSON maintainable.
- Keep mobile layouts usable for links shared in Chinese table tennis communities.

## Accessibility & Inclusion

Use high-contrast text, visible focus states, and responsive layouts that work on small phones. Avoid relying on color alone for meaning, especially in filters, ratings, and special tags.
